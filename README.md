# planning-lab

A small public test bed for GitHub's issue types and issue fields on a
**personal** (user-owned) account, which GitHub opened as a preview in late 2026.

It checks, with real issues and a workflow:

- which defaults a personal account starts with;
- whether types and fields can be created and set through the API; and
- whether a GitHub Actions workflow using the default `GITHUB_TOKEN` can
  classify issues automatically.

Findings are recorded in [FINDINGS.md](FINDINGS.md).
